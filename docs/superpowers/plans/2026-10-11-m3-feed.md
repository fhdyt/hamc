# M3 Live feed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Feed gabungan realtime (user, reply, thinking, tool, result) dari `state.db` semua profile, dengan filter, pencarian, riwayat, tampilan sesi, statistik harian per agent, dan modal Activity di Dashboard.

**Architecture:** Collector menambah event `feed` (kursor per profile, riwayat awal, `--cursors` setelah reconnect) dan `stats` pada event `agents`. Skrip kedua `collector/mc_query.py` dikirim lewat stdin per permintaan untuk teks penuh, riwayat lama, dan satu sesi. Main menyimpan kursor dan menjalankan `QueryRunner`. Renderer memakai store `feed`, daftar tervirtualisasi (`@tanstack/react-virtual`), `FeedView` yang dipakai layar, modal, dan kartu Activity.

**Tech Stack:** sama seperti M1/M2 ditambah `@tanstack/react-virtual`.

**Spec:** `docs/superpowers/specs/2026-10-11-m3-feed-design.md`. Konvensi, perintah test, dan batasan global mengikuti plan M1 dan M2.

## Global Constraints

- Semua batasan global M1 dan M2 berlaku: Zero-Change (hanya baca), tidak membuka `.env`/`auth.json`, perintah remote lewat `buildCommand`, skrip Python ASCII/stdlib, UI berbahasa Inggris, token Dracula, label berupa teks.
- Isi percakapan hanya di memori; tidak ke `app.db`, tidak ke log.
- Batas: 500 baris per profile per siklus, riwayat awal 60 baris per profile, store renderer 5000 item, teks penuh ≤ 65536 byte, keluaran query ≤ 1 MiB.
- Urutan feed terbaru di atas.

- Tulis berkas dengan escape (`\n`, regex) memakai tool Write/Edit, bukan heredoc `python -` (backslash ganda runtuh di shell ini).

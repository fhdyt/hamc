# M10a Skills Implementation Plan

**Goal:** The Skills screen (Library and Changes) over the real Hermes skill files, with pin, archive and install from hub through the official CLI.

**Spec:** `docs/superpowers/specs/2026-10-15-m10a-skills-design.md`

## Global Constraints

- UI strings English; collector stdlib-only and ASCII-only; every write is one confirmed `hermes` command built from individually quoted arguments; never `--force`.
- Each task ends with a commit pushed to `master` (the user asked for it).

## Tasks

1. **Collector.** Fixture `add_skills` (agent, hub, bundled, archived, stale and pinned skills, `.usage.json`, ledger with blobs); `skills_list`, `skill_read`, `skills_ledger`, `skills_blobs`; `tests/collector/test_skills.py`.
2. **Shared and main.** Schemas in `events.ts`, `shared/skills.ts` (`skillActionArgs`, regexes), `src/main/skills/actions.ts` (`SkillActionService`: pin, unpin, archive, restore, inspect, install, status), channels, zod, preload, `MissionApi`; fake `hermes curator|skills`; unit and integration tests.
3. **Renderer.** `lib/skills.ts`, `stores/skills.ts`, `skillsActions.ts`, `screens/Skills.tsx`, `screens/skills/*`, `styles/skills.css`, route and palette; unit tests and e2e.
4. **Docs.** Checklist steps 115 onward, CLAUDE.md.

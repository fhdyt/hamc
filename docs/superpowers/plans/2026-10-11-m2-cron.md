# M2 Cron Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Panel dan modal Cron (hanya baca) untuk semua profile Hermes, notifikasi OS saat job gagal, plus koreksi logika status agent M1 untuk susunan satu gateway per profile.

**Architecture:** Collector Python menambah event `cron` (dinormalisasi, hanya dikirim saat berubah). Main process menyimpan job di `CronStore`, membaca output run terakhir lewat `head -c` dengan path buatan sendiri, dan `CronWatcher` memutuskan notifikasi. Renderer menambah store `cron`, pustaka murni (`cron`, `cronExpr`), `CronPanel` di Dashboard dan `CronModal`.

**Tech Stack:** sama seperti M1 (Electron, React 19, Zustand, zod, ssh2, Vitest, pytest, Playwright).

**Spec:** `docs/superpowers/specs/2026-10-11-m2-cron-design.md`. Plan M1: `docs/superpowers/plans/2026-10-11-m1-foundation.md` (konvensi, struktur berkas, dan perintah test sama).

## Global Constraints

- Semua batasan global plan M1 berlaku (Zero-Change, tidak membaca `.env`/`auth.json`, perintah remote hanya lewat `buildCommand`, collector ASCII/stdlib, UI berbahasa Inggris, token Dracula, padding F-UI-9, label status berupa teks).
- M2 **hanya baca**: satu-satunya perintah remote baru adalah `head -c 65536 <path>`; path dibuat main process dan tidak pernah berasal dari renderer.
- Event `cron` dikirim hanya bila berubah (digest SHA-1) dan selalu pada pemindaian pertama; 500 job total, 200 per profile; prompt ≤ 4000 karakter, error ≤ 500 karakter.
- Notifikasi: baseline pada peta kosong, satu alert per run gagal baru, hanya saat jendela tidak fokus/diminimalkan/tersembunyi, tidak memuat prompt.
- Waktu absolut tampil dalam zona waktu komputer; offset VPS disebut di detail.
- Branch kerja: `m2-cron`. Commit diakhiri `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Gunakan tool Write (bukan heredoc panjang di Bash) untuk berkas besar; jalankan `npm run typecheck && npm test && npm run test:py` sebelum tiap commit.

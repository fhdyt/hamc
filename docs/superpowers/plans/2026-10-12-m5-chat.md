# M5 Chat Implementation Plan

> Inline execution (superpowers:executing-plans). Spec: `docs/superpowers/specs/2026-10-12-m5-chat-design.md`.

**Goal:** 1-on-1 chat with each agent through `hermes chat`, with streaming, tool chips, thinking from `state.db`, Stop, history, markdown, and SFTP file uploads.

**Global constraints:** Zero-Change (the only writes are the chat itself and uploads after Send); every remote argument individually quoted; message text never in a shell string or in `app.db`; no `--yolo`; UI strings English; renderer sandboxed (no arbitrary local paths from the renderer).

### Task 1: Collector queries
`chat_sessions {profile}` and `uploads_list {dir}` in `collector/mc_collector.py` + `tests/collector/test_chat.py`; fixture gets a `mission-control` session. Commit.

### Task 2: Chat service
Shared `ChatEvent`/IPC, tolerant stream parser (`src/main/chat/parser.ts`), `ChatService`, session mapping in `app.db`, flag probing, fake `hermes` in the fake SSH server (writes `state.db`), unit + integration tests. Commit.

### Task 3: Uploads
`ConnectionManager.sftp()`, `UploadService` (register, upload, cancel, list, delete), main-side picker, preload `webUtils` path resolver, fake SFTP server, tests. Commit.

### Task 4: Renderer data
`stores/chat.ts`, `lib/chat.ts` (merge database items with the live turn, attachment block), `components/Markdown.tsx` + `lib/markdown.ts`, bootstrap wiring, unit tests. Commit.

### Task 5: Screens
Chat screen, Conversation, Composer with attachments, History menu, Dashboard chat room, CSS. Commit.

### Task 6: Settings → Uploads and the container warning
Uploads tab (list, delete with confirmation), backend warning on attach. Commit.

### Task 7: E2E, docs, memory, merge
Playwright specs, manual VPS checklist (including the `hermes chat --help` spike), CLAUDE.md, memory, full verification, merge into master.
